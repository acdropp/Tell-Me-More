# Tell Me More

A friendly conversation game with 720 questions across 16 chapters.

This GitHub Pages edition runs entirely in the browser. Each visitor has their own locally saved checkmarks and shuffled layout; there are no accounts or external APIs. Progress is specific to this browser and can be removed by clearing site data.

## Publish

In this repository, open **Settings → Pages**. Choose **Deploy from a branch**, select **main** and **/ (root)**, then save. The Pages settings will show the published address when deployment finishes.

## Files

- `index.html`, `app.js`, `style.css`, `favicon.svg`, `.nojekyll`: ready to publish; no build step needed.
- `src/main.tsx`, `src/questions.json`, `src/style.css`: editable source.

The site preserves tap-to-reveal cards, reading popups, SKIP reshuffling, numbered checklists, responsive grids, and the pinned chapter navigation.
